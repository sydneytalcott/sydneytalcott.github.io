# Sydney Talcott

Personal site at [sydneytalcott.com](https://sydneytalcott.com), built as a [Zazen](https://zazen.dev) site.

- `zazen.json` — content, schemas, navigation and settings
- `registry/` — templates, components, styles and scripts
- `media/` — images

Open this repository in [Zazen.dev](https://zazen.dev) to edit visually and publish.
